# AegisRisk AI - Next-Gen Brand Protection & Threat Mitigation Platform

AegisRisk AI is an automated digital risk protection dashboard engineered to neutralize brand impersonation, visual counterfeiting, and phishing threats across online platforms.

---

## 🔒 Primary Capabilities

* **Real-time Brand Reconnaissance:** Instantaneous multi-vector OSINT telemetry scanning across modern web spaces.
* **Computer Vision Authentication:** Evaluates similarity ratios between official corporate badges and fraudulent profile avatars using multi-pass perceptual hashing.
* **Integrated Remediation Pipeline:** Dispatches single-click DMCA takedown signals directly to domain registrars and social platforms.
* **Unified SOC Telemetry:** Interactive threat indexing displaying risk severity scores, active scams, and whitelisted infrastructure.

---

## ⚡ Built With

* **Frontend:** Next.js framework + React
* **Styling Layer:** Tailwind CSS with Shadcn UI components
* **Visual Match Engine:** Custom Perceptual Hashing & Vector Embedding Comparison
* **Hosting:** Vercel Global Edge Network
